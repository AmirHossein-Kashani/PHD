### [[GENEDISCO]]

we have bunch of formula or melocules

there is two thing to maximise :
- **Maximize Target Discovery Rate:** Algorithms must select the most promising gene targets for interventional experiments in order to maximize the actual discovery rate of interesting or therapeutically relevant targets.
- **Maximize Model Performance:** Algorithms must select a batch of gene targets for experiments that will maximize the predictive accuracy and overall performance of the underlying machine learning model once it is trained on that newly acquired data.
