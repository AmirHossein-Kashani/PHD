The difference between subagents, skills, MCP

the main difference between MCP and skills is that in MCP all the information of the tools will be mention but in skills, we only mention initial name and description at first step and if the tool select we will show the complete descritption, moreover we can add some data with reference in .skill file that help to find more detail (it could be conditional for example if you need this check `booking.md`)
